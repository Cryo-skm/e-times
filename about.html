作品简介

e次元（e-times）是一个把「二次元谷子经济」与「银行金融服务」缝合在一起的数字空间提案。作品从一个所有人都熟悉的场景出发——打开手机银行 App——但不再止步于余额与转账：用户从银行端的多个入口推门而入，落进一个樱花粉与天蓝交织的虚拟社区，在那里完成鉴真、估值、交易、托管、信贷、收藏与社交的完整闭环。

它要回应的一个真实问题是：谷子（动漫周边）交易长期处在「信息不对称 + 信任缺失」的灰色地带——真伪难辨、价格无锚、先款后货跑单频发、纠纷无据可依。而银行恰好握着这个市场最稀缺的三样东西：信用、资金与风控能力。作品把这三样东西包装成一套对年轻人友好的产品，让金融服务以「不打扰」的方式进入一个高频、高情感投入的消费场景。

因此在设计上有一个刻意的取舍：银行端只是入口，e次元 才是主角。一进门，视觉语言立刻换气——从银行的红色与规整，切换到梦幻的二次元空间，只保留最低限度的金融语义（额度、积分、分期、购买）。

核心功能

三大引擎 谷享 · 智能消费引擎 一句话说出想要什么，系统跨渠道比价、判断真伪、跟踪到货，必要时替你下单。
三大引擎 出谷通 · 交易保障引擎 基于智能合约的第三方资金托管与验货期管理，把钱和货的交付对齐，压住跑单风险。
三大引擎 藏馆 · 数字社交引擎 AR 虚拟藏馆，把藏品投影到现实场景，展示、策展、分享，让「收藏」被看见。
金融服务 谷卡 · 谷子信贷 面向谷子爱好者的消费信贷与灵活分期，让热爱不被预算限制。

系统功能矩阵

  • AI 鉴真系统——上传商品图片，结合图像识别与数据库比对，输出真伪判断结果。
  • 智能估值系统——基于历史成交与市场热度，给出价格区间与趋势分析。
  • 交易保障系统——资金托管、验货期管理、纠纷凭证留存。
  • 谷子信贷（谷卡）——授信、分期、还款与额度管理。
  • 谷享代购比价——跨渠道需求托管与全网比价。
  • 时空谷馆 / 个人虚拟藏馆——藏品陈列、主题策展、价值档案。
  • 谷圈广场 · 好友共创——晒谷、情报、出回血与同好社交。
  • AR 体验——数字藏品与现实场景的投影与合影创作。

形态与入口

移动端：手机银行外壳 → e次元

以模拟的工行手机银行 App 为外壳，在首页、生活页、消息中心、轮播等多个入口放置通往 e次元 的门。点进去会先经过一段「推门」转场，再落进社区——并且不同入口会落到 e次元 内部不同的位置（如谷圈广场、商城、时空谷馆、谷享代购），形成一套像洞穴系统一样复杂但合理的动线。

PC 端：网上银行外壳 → e次元 工作台

左侧为 e次元 的十三项功能菜单（首页 / 商品推荐 / AI 鉴真 / 智能估值 / 交易保障 / 谷子信贷 / 我的收藏 / 个人虚拟藏馆 / 社区广场 / 好友共创 / AR 体验 / 消息中心 / 个人中心），右侧是完整的工作台视图，顶部保留模拟网银的账户概览作为「入口」语境。

技术实现

  • 零外部依赖——原生 HTML / CSS / JavaScript 手写，不引入任何框架或第三方库，全部资源本地化。
  • 纯静态托管——全站相对路径，可直接部署在任意静态空间；当前托管于 GitHub Pages。
  • PWA 支持——提供 manifest 与 Service Worker，移动端「添加到主屏幕」后可离线打开。
  • 素材原创——站内插画与角色均为原创绘制，不使用任何第三方作品素材。
  • 动效与转场——推门转场、花瓣飘落、玻璃拟态与渐变描边均为 CSS 实现，含系统的动效降级适配。
